What it does

Prompt Counter is a tiny agent skill. Once installed, you type /prompt-count in Cursor, Claude Code or Codex and the agent runs a local Python script that reads the transcripts your tool already keeps on disk. You get, per conversation and per project:

Ce que ça fait

Prompt Counter est un petit skill d'agent. Une fois installé, tu tapes /prompt-count dans Cursor, Claude Code ou Codex et l'agent lance un script Python local qui lit les transcripts que ton outil garde déjà sur disque. Tu obtiens, par conversation et par projet :

Unique prompts

Prompts uniques

Your real messages. Duplicates, the tool's automatic prompts and the /prompt-count call itself are excluded.

Tes vrais messages. Les doublons, les prompts automatiques de l'outil et l'appel /prompt-count lui-même sont exclus.

Active time

Temps actif

Time you actually spent exchanging with the agent. Nights, lunch breaks and a PC left on do not count.

Le temps réellement passé à échanger avec l'agent. Les nuits, les pauses et un PC laissé allumé ne comptent pas.

Per workspace

Par workspace

Each project is reported on its own. Use --all for a machine-wide view, one block per project.

Chaque projet est rapporté séparément. --all donne la vue machine entière, un bloc par projet.

How active time is computed

Comment le temps actif est calculé

Une conversation est une liste de tes prompts horodatés, plus les appels d'outils de l'agent entre deux. Chaque écart entre deux prompts est crédité ainsi :

Install

Installation

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/johnban-coder/prompt-counter/main/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/johnban-coder/prompt-counter/main/install.ps1 | iex

The installer copies SKILL.md and scripts/ into ~/.cursor/skills, ~/.claude/skills, ~/.codex/skills and ~/.agents/skills. Pick targets with TARGETS="cursor claude" / -Targets cursor,claude. Requires Python 3.10+.

L'installeur copie SKILL.md et scripts/ dans ~/.cursor/skills, ~/.claude/skills, ~/.codex/skills et ~/.agents/skills. Choisis les cibles avec TARGETS="cursor claude" / -Targets cursor,claude. Nécessite Python 3.10+.

Privacy

Confidentialité

Everything runs on your machine. No network calls, no telemetry, no dependency to install. The report only contains a short excerpt (first line, ≤ 72 characters) of the first prompt of each conversation, used as a title. The script is one readable file: scripts/count.py.

Tout tourne sur ta machine. Aucun appel réseau, aucune télémétrie, aucune dépendance à installer. Le rapport ne contient qu'un court extrait (première ligne, ≤ 72 caractères) du premier prompt de chaque conversation, utilisé comme titre. Le script tient en un fichier lisible : scripts/count.py.
